**Ticket**: open source / sem modelo de cobrança claro no PRD (distribuído como pacote npm)

**Fonte**: `tmp/produtos-extract/Legacy-Squad-PRD.txt` (PRD completo v0.1.15)

## Resumo
Plataforma que permite criar **squads** (equipes de agentes de IA) que trabalham juntos para automatizar tarefas complexas. Cada squad é composto por agentes especializados (pesquisador, copywriter, designer, revisor) que executam fluxos com **aprovação humana em checkpoints**. Usa Claude Code como orquestrador, Playwright para web, Canva para design, e múltiplas skills prontas (Apify, Blotato, Resend etc.).

Foco: marketing, pesquisa, conteúdo e automações repetitivas. Diferencial: linguagem natural (não configuração), aprovação humana obrigatória em pontos críticos, memória persistente por squad.
